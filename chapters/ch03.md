# 第3章 主线剧情的分章与分阶段发展流程

> 本章聚焦《人狼村之谜》（Rei-Jin-G-Lu-P / Raging Loop，KEMCO 发行，编剧 amphibian，2015 年手游首发、2017 年登陆多平台、2024 年推出次世代版 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C)）**主线剧情是如何被"分阶段"讲出来的**。核心命题是：这是一部"轮回即叙事结构"的作品——作者没有用线性章节，而是用一次次的死亡回溯（周目），把世界规则、人物关系与村庄阴谋一层层"解锁"给玩家。本章只梳理"流程与信息递进"，把"转折与悬念引爆点"留给第4章。

---

## 3.1 周目结构总览：剧本导图与 KEY 系统

游戏在流程上采用一张**"剧本导图"（Scenario Chart）**，玩家每次死亡后都回到"骑摩托迷路、坠崖前夜"的起点，带着记忆重新推进。导图上的主干节点依次为：**Dense Mist（浓雾）→ Yomi（黄泉）→ Infiltration（潜入）→ Wit（机知/乐境虏逋）→ Darkness（暗黑/零人势力）→ Myth（迷）**[Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)[PSNine 奖杯列表](https://www.psnine.com/psngame/18014)。其中 **Yomi / Wit / Darkness / Myth 是四个"主线结局（Main Ending）"，必须按顺序解锁**：Wit 需在 Yomi 之后，Darkness 需在前两者之后，Myth 则需集齐其余三条线后方可开启 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

推动这一结构的是 **KEY（剧情钥匙）系统**。主角在每一轮中"作死"、触发各类死亡或分歧结局，都会拾取若干 KEY；这些 KEY 解锁后续周目里原本不可选的对话与行动分支 [机核 GCORES](https://www.gcores.com/talks/1005995)。据机核评测，游戏共设有约 **20 个 KEY**，即便只想打出一个伪结局也至少要死一次；每个死亡结局还会弹出"是否需要提示"，直接告诉玩家拿到了哪个 KEY、解锁了哪里的选项 [机核 GCORES](https://www.gcores.com/talks/1005995)。换言之，**周目不是"重复游玩"，而是"信息累积"**——每多活/多死一轮，主角（与玩家）掌握的事实就多一块。

> 术语约定：下文以"第 N 周目"对应四个主线结局 Yomi / Wit / Darkness / Myth（与本研究报告大纲一致）；Dense Mist、Infiltration 及二十余个 Bad Ending 视为穿插其间的"子阶段/支线"，用于积累 KEY。

## 3.2 第1周目 · Yomi（黄泉）：初入村庄与死亡循环开启

**主角目标**：作为迷路的摩托旅行者房石阳明，在坠崖生还后被芹泽千枝实救入休水村，首要诉求是修好摩托、赶在起雾前离开；随后被动卷入仪式。

**关键事件**：
1. 阳明因车祸误入与世隔绝的休水村，被千枝实收留一夜 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C)。
2. 次日浓雾笼罩，"黄泉忌之宴"开幕：村民宣称被人类弑杀的"狼神"复活，每晚狼人猎杀一人，白天由村民投票将疑似狼神者"吊死"；申奈明神赋予加护——猿猴（双人互知）、乌鸦（验尸）、蜘蛛（守护）、蛇（探查）[机核 GCORES](https://www.gcores.com/talks/1005995)。
3. **阳明被排除在"游戏之外"**，以旁观者身份目睹宴会，未能参与投票 [机核 GCORES](https://www.gcores.com/talks/1005995)。
4. 当晚他看见科学难以解释的"人狼"，最终被狼杀害，却在意识清醒时回到了迷路坠崖的最初之夜 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C)。

**获得的信息（信息增量①）**：建立起世界的最底层规则——黄泉忌之宴的"狼人杀"框架、加护职能、以及**死亡回溯/轮回机制**（保留记忆回到起点）。此结局提供 Key 04 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因**：阳明作为"局外人"无投票权，狼方在宴会上取胜，他本人遭狼杀害；第一次触发 loop。此时他对村庄阴谋一无所知，仅完成了"规则认知"这一最小闭环。

## 3.3 第2周目 · Wit（机知/乐境虏逋）：试探规则与人物

**主角目标**：带着上周目的记忆主动"入场"，以参与者身份（如获得"蛇"的加护）参与推理、存活并弄清村庄到底发生了什么 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。

**关键事件**：
1. 经 **Infiltration（潜入）** 子阶段：阳明在村内探查、被盘问（不同应答解锁不同 KEY），逐步熟悉地理与人脉 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。
2. 正式进入宴会，每轮"调查"一名村民即解锁对应角色的秘密 KEY（如"记者真相""少女真相""天才真相""医生真相"等）[ScorpioOfShadows 攻略](https://www.scorpioofshadows.com/post/raging-loop)。
3. 主线走向"狼阵营暴露→千枝实自杀→宴会被迫中断"；或主角存活离村后发现村庄已尸横遍野 [Into Sanctuary 社区剧情梳理](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)。
4. 出现对规则的质疑节点——如"第五职能/貉（狸）"的登场，动摇了"神明指派角色"的确定性 [机核 GCORES](https://www.gcores.com/talks/1005995)。

**获得的信息（信息增量②）**：从"旁观"转入"参与"，**人物关系网与各自秘密被系统性展开**；对宴会规则的"可质疑性"初露端倪；千枝实的身份出现可疑线索。此结局提供 Key 16 [Fandom source](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因（来源存在分歧，需标注）**：关于 Wit 线的收束，不同二手来源描述不一——英文社区梳理称"主角存活离开村庄、回来却发现全村已死" [Into Sanctuary](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)；而若干中文聚合站则称"狼阵营暴露后千枝实自杀，宴会被迫结束，但后续李花子被清之介杀害、主角绝望跳崖" [魔趣网](https://www.mfunz.com/game/15391.html)。二者指向"本周目仍无法真正破局"的结论一致，但具体死法存异，建议以游戏本体为准。

## 3.4 第3周目 · Darkness（暗黑/零人势力）：阴谋浮出水面

**主角目标**：采取更具进攻性/疯狂的立场（宣称自己是狼、或主动设局），深挖宴会"谁在操控"的真相。

**关键事件**：
1. 周目内出现"All or Nothing"式抉择：可走"屠杀（Massacre）""不杀一人""设陷阱"等分支 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。
2. 人为操控的痕迹集中暴露：**电子锁自动开合、麻醉迷香、恶狗撕咬尸体、摄像头监视、三车家成员扮演"最外围的狼"**——宴会并非纯超自然，而是被现实科技手段控盘 [Into Sanctuary 社区剧情梳理](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)。
3. "狼爷爷"木田德治作为执法者，半夜清除违反规则者，恶狗辅助 [斗鱼鱼吧 周目详解](https://yubam.douyu.com/post/774168691675054042)。
4. 巨型怪物（即回末李花子所召唤的"大狼人"）登场，loop 的更高维本质（梦境覆盖、由"绵羊/咩子"等存在操控）显现 [Into Sanctuary](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)[NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331)。

**获得的信息（信息增量③）**：**村庄真相从"迷信/神罚"叙事转向"人为阴谋"叙事**——黄泉忌之宴是被三车家（三車）系统性操控的维稳私刑；狼爷爷系藤良连环杀人案共犯、以人口交易字据要挟三车家换取保命 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。此结局提供 Key 20，恰为解锁 Myth 所需 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因**：即便以狼身杀光村民（除白发女），仍无法逃出 loop；怪物出现后主角意识到自己被困于"某人的梦境"，单一周目的暴力破局无效，必须回到信息层面。

## 3.5 第4周目 · Myth（迷）：真相与核心解密

**主角目标**：集齐开启真结局所需的 KEY（含由 Traitor 结局取得的 Key 01），彻底揭开全部谜团并终结轮回 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**关键事件**：
1. 与千枝实确认彼此都能保存记忆回溯——千枝实已历经"远不止数百次"的轮回，心智近乎崩溃 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。
2. 与"绵羊（羊）"对话，获知 loop 的本质是"梦境被某人覆盖现实"、幕后黑手通过轮回试错企图召唤怪物毁灭现实 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。
3. 与三车家、回末李花子正面对峙，收束六百年信仰流变、三车家人口交易与统治、宴会的"维稳+打压"本质，以及超自然（貉神/咩子）与人为操控双重结构 [NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331)。
4. 以"天谜地解"方式破局，说服村民停止杀戮、揭穿黄泉忌之宴全貌，达成共同结局 [斗鱼鱼吧 周目详解](https://yubam.douyu.com/post/774168691675054042)。

**获得的信息（信息增量④·收束）**：所有碎片化线索在此整合为完整真相——**黄泉忌之宴既是三车家借信仰实施统治的人为私刑，又是被超自然力量（貉神信仰者）借"梦境/loop"利用的舞台**；男主房石阳明自身是否具备隐性能力在官方 QA 与玩家间仍存争议 [NGA 玩家讨论](https://ngabbs.com/read.php?tid=31223780)。

**被阻断 / 死亡的原因**：前三个周目无论"被动死亡""参与失败"还是"暴力破局"均无法结束循环；唯有集齐信息、以正确方式（共同对抗/天谜地解）回应，loop 才真正闭合。

| 现在 | 房石阳明车祸误入休水，loop 开启 | [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C) |

**B. 游戏内 loop 推进（本研究第3章主线）**
1. **Dense Mist（浓雾）**：坠崖生还→入村→起雾→初见人狼→首次死亡，取得初期 KEY。
2. **第1周目 Yomi**：旁观宴会、狼方胜、被杀害→loop；建立规则认知（Key 04）。
3. **Infiltration（潜入）**：村内探查与被盘问，解锁人物 KEY。
4. **第2周目 Wit**：主动入场推理、人物秘密展开→仍无法破局（Key 16）。
5. **第3周目 Darkness**：人为操控痕迹（电子锁/迷香/恶狗/三车家）、狼爷爷真身、怪物登场→真相转向阴谋（Key 20）。
6. **第4周目 Myth**：集齐 KEY，与千枝实/绵羊/三车家对峙，天谜地解→真结局，loop 闭合（需 Key 01）。

## 3.8 引爆性质节点清单（预留第4章展开）

以下"悬念引爆点"在本章仅列出并作简要说明，**详细铺垫与引爆机制交由第4章分析**：

1. **狼爷爷（木田德治）真面目揭露**：藤良连环杀人案共犯、以字据要挟三车家的执法者——将"村中慈祥老者"翻转为幕后打手 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。
2. **芹泽千枝实 = 三车千枝实**：身负黄泉污染、被三车家放逐，其吊坠与"三之仓"狂犬病狗咬伤的过往，是身份反转的核心 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。
3. **"绵羊/羊"与幕后黑手**：loop 实为某存在用"梦境覆盖现实"、借轮回试错召唤怪物——把"死亡回溯"从设定升格为叙事谜底 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&ordertype=1&tid=11182)。
4. **回末李花子 = 巨型怪物（大狼人）**：超自然线与人为线的最终交汇点 [NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331)。
5. **"天谜地解"破局时刻**：以科学/逻辑瓦解迷信、说服村民停手，完成 loop 闭合的终极转折。

## 3.9 小结

《人狼村之谜》的主线并非按"第一章/第二章"线性铺开，而是借 **Yomi→Wit→Darkness→Myth 四个主线周目 + Dense Mist/Infiltration 等子阶段** 的轮回结构，把信息像拼图一样分轮次交付。主角每多死/多活一轮，就多掌握一块事实：从"规则认知"（Yomi），到"人物关系网"（Wit），再到"阴谋本质"（Darkness），最终在 Myth 收束为完整真相。KEY 系统则从机制上保证了"信息递进"与"玩家探索"的同构——这正是该剧本文体最被评测肯定的精巧之处 [机核 GCORES](https://www.gcores.com/talks/1005995)[VG 电玩帮 评测](https://www.vgover.com/news/39034)。下一章将聚焦上述"引爆点"是如何被逐层铺设并集中释放的。
