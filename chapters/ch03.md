# 第3章 主线剧情的分章与分阶段发展流程

> 本章聚焦《人狼村之谜》（Rei-Jin-G-Lu-P / Raging Loop，KEMCO 发行，编剧 amphibian，2015 年手游首发、2017 年登陆多平台、2024 年推出次世代版 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/人狼村之谜)）**主线剧情是如何被"分阶段"讲出来的**。核心命题是：这是一部"轮回即叙事结构"的作品——作者没有用线性章节，而是用一次次的死亡回溯（周目），把世界规则、人物关系与村庄阴谋一层层"解锁"给玩家。本章只梳理"流程与信息递进"，把"转折与悬念引爆点"留给第4章。

---

## 3.1 周目结构总览：剧本导图与 KEY 系统

游戏在流程上采用一张**"剧本导图"（Scenario Chart）**，玩家每次死亡后都回到"骑摩托迷路、坠崖前夜"的起点，带着记忆重新推进。导图上的主干节点依次为：**Dense Mist（浓雾）→ Yomi（黄泉）→ Infiltration（潜入）→ Wit（机知）→ Darkness（暗黑）→ Myth（神明）**[Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)[PSNine 奖杯列表](https://www.psnine.com/psngame/18014)。其中 **Yomi / Wit / Darkness / Myth 是四个"主线结局（Main Ending）"，必须按顺序解锁**：Wit 需在 Yomi 之后，Darkness 需在前两者之后，Myth 则需集齐其余三条线后方可开启 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

推动这一结构的是 **KEY（剧情钥匙）系统**。主角在每一轮中"作死"、触发各类死亡或分歧结局，都会拾取若干 KEY；这些 KEY 解锁后续周目里原本不可选的对话与行动分支 [机核 GCORES](https://www.gcores.com/talks/1005995)。据机核评测，游戏共设有约 **20 个 KEY**，即便只想打出一个伪结局也至少要死一次；每个死亡结局还会弹出"是否需要提示"，直接告诉玩家拿到了哪个 KEY、解锁了哪里的选项 [机核 GCORES](https://www.gcores.com/talks/1005995)。换言之，**周目不是"重复游玩"，而是"信息累积"**——每多活/多死一轮，主角（与玩家）掌握的事实就多一块。

> 术语约定：下文以"第 N 周目"对应四个主线结局 Yomi（黄泉）／Wit（机知）／Darkness（暗黑）／Myth（神明），与本报告跨章口径一致；"乐境虏逋""零人势力"系章题副名（来源未核实）、"迷"系 Myth 的异译，正文不再并列使用。Dense Mist（浓雾）、Infiltration（潜入）及二十余个 Bad Ending 视为穿插其间的"子阶段/支线"，用于积累 KEY；"夕雾"仅见于开场歌谣，不作子阶段译名。另须区分**咩子**（黑山羊幼崽，以迷路幼童形象出现）与**羊型布偶"绵羊"**（自陈协助阳明保留记忆者）——二者是否同一存在，剧本转写未点明，本报告不作定论。

## 3.2 第1周目 · Yomi（黄泉）：初入村庄与死亡循环开启

**主角目标**：作为迷路的摩托旅行者房石阳明，在坠崖生还后被芹泽千枝实救入休水村，首要诉求是修好摩托、赶在起雾前离开；随后被动卷入仪式。

**关键事件**：
1. 阳明因车祸误入与世隔绝的休水村，被千枝实收留一夜 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/人狼村之谜)。
2. 次日浓雾笼罩，"黄泉忌之宴"开幕：村民宣称被人类弑杀的"狼神"复活，每晚狼人猎杀一人，白天由村民投票将疑似狼神者"吊死"；申奈明神赋予加护——猿猴（双人互知）、乌鸦（验尸）、蜘蛛（守护）、蛇（探查）[机核 GCORES](https://www.gcores.com/talks/1005995)。
3. **阳明被排除在"游戏之外"**，以旁观者身份目睹宴会，未能参与投票 [机核 GCORES](https://www.gcores.com/talks/1005995)。
4. 当晚他看见科学难以解释的"人狼"，最终被狼杀害，却在意识清醒时回到了迷路坠崖的最初之夜 [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/人狼村之谜)。

**获得的信息（信息增量①）**：建立起世界的最底层规则——黄泉忌之宴的"狼人杀"框架、加护职能、以及**死亡回溯/轮回机制**（保留记忆回到起点）。此结局提供 Key 04 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因**：阳明作为"局外人"无投票权，狼方在宴会上取胜，他本人遭狼杀害；第一次触发 loop。此时他对村庄阴谋一无所知，仅完成了"规则认知"这一最小闭环。

## 3.3 第2周目 · Wit（机知）：试探规则与人物——"赢了推理，仍被夺走一切"

**主角目标**：带着上周目的记忆主动"入场"，以参与者身份（如获得"蛇"的加护）参与推理、存活并弄清村庄到底发生了什么 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。

**关键事件**：
1. 经 **Infiltration（潜入）** 子阶段：阳明在村内探查、被盘问（不同应答解锁不同 KEY），逐步熟悉地理与人脉 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。
2. 正式进入宴会，每轮"调查"一名村民即解锁对应角色的秘密 KEY（如"记者真相""少女真相""天才真相""医生真相"等）[ScorpioOfShadows 攻略](https://www.scorpioofshadows.com/post/raging-loop)。
3. 主线收束为一条**六步序列**（依据逐场景剧本转写）：阳明以"蛇"识破狼方为**酿田近望与芹泽千枝实**（近望以能里家用药知识提取乌头汁、随机向碗中下毒）→ 二人抽出锯短霰弹枪，但**子弹已被阳明事先换成模拟弹** → 处置分歧（宽造主张继续吊死、泰长主张控制二人待雾霁后交法律制裁），阳明指出本周目的千枝实是连队友都可牺牲的冷血杀手，于是**大家吊死近望、千枝实跳入皿永自尽** → **次日雾霁天晴、宴会正式宣告结束**，八名受害者遗体却离奇消失，阳明在滩上拾得一枚刻有三道黄泉狼印记的吊坠，**日口庄治率救援队入村救出活人** → 李花子表白，阳明承诺安顿好咩子后归来与她共同生活 → 阳明归来，发现**已发狂的能里清之介吊死了李花子并杀死其余生还者**；阳明杀死清之介，在浓雾中从山崖跳入皿永——机知 END（[雾雨小镇·剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)）。
4. 出现对规则的质疑节点——如"第五职能/貉（狸）"的登场，动摇了"神明指派角色"的确定性 [机核 GCORES](https://www.gcores.com/talks/1005995)。

**获得的信息（信息增量②）**：从"旁观"转入"参与"，**人物关系网与各自秘密被系统性展开**；对宴会规则的"可质疑性"初露端倪；千枝实的身份出现可疑线索。此结局提供 Key 16 [Fandom source](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因**：本周目主角**在规则意义上确实获胜**——狼方被识破并处决、雾霁天晴、宴会正式结束、活人被救援队救出、休水一度回归正轨。断裂发生在"胜利之后"：他离村处理事务再回来时，生还者已被发狂的能里清之介尽杀，李花子死于绞索，阳明手刃清之介后自己跳入皿永。因此机知线的悲剧不是"推理失败"，而是**推理成功仍被更高一层的机制夺走全部结果**——下一轮回开头对本段游戏的回顾正是：他身为蛇，"虽然成功带领大家击败了狼势力，但最终却像是被某种力量玩弄着一般，失去了一切"（[雾雨小镇·剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)）。需特别说明：早期英文社区梳理的"存活离村、归来发现全村已死"（[Into Sanctuary 社区剧情梳理](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)）与中文聚合站的"千枝实自杀、李花子被杀、主角绝望跳崖"（[魔趣网](https://www.mfunz.com/game/15391.html)）**并非互斥异说**，而是上述同一条结局线的第 4～6 步与第 3～6 步——三份描述各取一个截断点，此前被误记为"来源冲突"。

## 3.4 第3周目 · Darkness（暗黑）：阴谋浮出水面

**主角目标**：采取更具进攻性/疯狂的立场（宣称自己是狼、或主动设局），深挖宴会"谁在操控"的真相。

**关键事件**：
1. 周目内出现"All or Nothing"式抉择：可走"屠杀（Massacre）""不杀一人""设陷阱"等分支 [VN Paths 流程攻略](https://vnpaths.com/raging-loop-walkthrough-and-guide/)。
2. 人为操控的痕迹集中暴露：**电子锁自动开合、麻醉迷香、恶狗撕咬尸体、摄像头监视、三车家成员扮演"最外围的狼"**——宴会并非纯超自然，而是被现实科技手段控盘 [Into Sanctuary 社区剧情梳理](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)。
3. "狼爷爷"木田德治作为执法者，半夜清除违反规则者，恶狗辅助 [斗鱼鱼吧 周目详解](https://yubam.douyu.com/post/774168691675054042)。
4. 巨型怪物（即回末李花子所召唤的"大狼人"）登场；羊型布偶"绵羊"现身，自陈"这附近的一部分现实已被梦境吞噬"、并"可以帮助阳明在轮回中保留记忆"，loop 的更高维本质（梦境覆盖现实）由此显现 [Into Sanctuary](https://intosanctuary.com/index.php?threads/raging-loop-a-gauche-review-production.922/)[NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331)。

**获得的信息（信息增量③）**：**村庄真相从"迷信/神罚"叙事转向"人为阴谋"叙事**——黄泉忌之宴是被三车家系统性操控的维稳私刑；狼爷爷系藤良连环杀人案共犯、以人口交易字据要挟三车家换取保命 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)。此结局提供 Key 20，恰为解锁 Myth 所需 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**被阻断 / 死亡的原因**：即便以狼身杀光村民（除白发女），仍无法逃出 loop；怪物出现后主角意识到自己被困于"某人的梦境"，单一周目的暴力破局无效，必须回到信息层面。

## 3.5 第4周目 · Myth（神明）：真相与核心解密

**主角目标**：集齐开启真结局所需的 KEY（含由 Traitor 结局取得的 Key 01），彻底揭开全部谜团并终结轮回 [Fandom Endings](https://ragingloop.fandom.com/wiki/Endings)。

**关键事件**：
1. 与千枝实确认彼此都能保存记忆回溯——千枝实已历经"远不止数百次"的轮回，心智近乎崩溃 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)。
2. 与羊型布偶"绵羊"对话，获知 loop 的本质是"一部分现实已被梦境吞噬"；而**编织这一无限轮回梦境、借轮回不断试错的发动者是回末李花子**（梦之土蜘蛛），回溯"似乎是以幕后黑手的死亡触发"，咩子（黑山羊幼崽）则是在最后一次轮回**吞噬土蜘蛛、从而终结了这场试错**的存在 [雾雨小镇 剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)。（"幕后黑手借轮回试错召唤怪物毁灭现实"系社区梳理的简化表述，与游戏文本的分工并不完全等同。）
3. 与三车家、回末李花子正面对峙，收束六百年信仰流变、三车家人口交易与统治、宴会的"维稳+打压"本质，以及超自然（貉神/咩子）与人为操控双重结构 [NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331)。
4. 以"天谜地解"方式破局，说服村民停止杀戮、揭穿黄泉忌之宴全貌，达成共同结局 [斗鱼鱼吧 周目详解](https://yubam.douyu.com/post/774168691675054042)。

**获得的信息（信息增量④·收束）**：所有碎片化线索在此整合为完整真相——**黄泉忌之宴既是三车家借信仰实施统治的人为私刑，又是被超自然力量（貉神信仰者）借"梦境/loop"利用的舞台**。至于男主房石阳明自身是否具备隐性异能：据玩家社区对作者 QA 的转述，官方已明确他**并非**超能力者，番外篇"绵羊"的相关说法仅是某角色的猜测、并非定论（[NGA 玩家讨论](https://ngabbs.com/read.php?tid=31223780)；本报告未见该 QA 的一手文本，故按"经社区转述"引用）。评论者主张的"主角或有把超自然合理化为平凡的无意识异能"属**阐释层**命题，其讨论见第 4 章 4.5。

**被阻断 / 死亡的原因**：前三个周目无论"被动死亡""参与失败"还是"暴力破局"均无法结束循环；唯有集齐信息、以正确方式（共同对抗/天谜地解）回应，loop 才真正闭合。

## 3.6 关键事件流程时间线

**A. 背景历史脉络（游戏内"过去"）**
| 时段 | 事件 | 来源 |
|------|------|------|
| 约六百年前 | "狼之乡"时期为避免野狼侵袭而**献祭一家三口为人柱**；由此诞生的**三位狼神取代古神，并把古神贬为侍从——该侍从即后来附身卷岛春的"貉神"**。游戏内"六百年前真正的黄泉狼神具"为这一层提供了直接的年代锚。此后发展为伏良村 | [雾雨小镇·剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)、[233乐园 设定梳理](https://www.233leyuan.com/post-detail/1956258247720419328) |
| 伏良繁荣期 → 明治年间 | 伏良村繁荣、始有失踪记录，阳明据此推定黄泉忌之宴即始于该时期；伏良地区按**人体结构**划分为发、肝、骨、足、爪等部分，由各大家族分别掌管；休水当时称"休主"，拆字即"人柱"。**明治时期的宗教治理重创申奈信仰**，许多传统被迫终止（造"申奈"的具体年代游戏文本未给出，只有"在伏良繁荣期之后、明治宗教治理之前"的相对位置） | [雾雨小镇·剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)、[2023game 设定整理](https://www.2023game.com/sgame/cn/238275.html) |
| 约六十年前（太平洋战争） | 藤良连环杀人案（枥谷喜平、共犯木田德治/狼爷爷）；三车家人口交易字据现世，真正的黄泉忌之宴开端 | [2023game 设定整理](https://www.2023game.com/sgame/cn/238275.html) |
| 约二十年前 | 长者自海外带回传染病，休水霍乱 | [2023game 设定整理](https://www.2023game.com/sgame/cn/238275.html) |
| 15 年前 / 8 年前 | 多次"有组织控盘"的宴会，用于维稳与清除不稳定分子。游戏内证据为**能里家地下室密室中的历代家主笔记**：清之介的曾祖父调查申奈狂热之因、其祖父死于十五年前的宴会、其父八年前在休水服毒（阳明判为灭口） | [雾雨小镇·剧本整理](https://www.mistytown.cn/forum.php?mod=viewthread&tid=11182)、[NGA 玩家讨论](https://bbs.nga.cn/read.php?page=1&tid=41652331) |
| 现在 | 房石阳明车祸误入休水，loop 开启 | [萌娘百科](https://mobile.moegirl.org.cn/zh-hant/人狼村之谜) |

**B. 游戏内 loop 推进（本研究第3章主线）**
1. **Dense Mist（浓雾）**：坠崖生还→入村→起雾→初见人狼→首次死亡，取得初期 KEY。
2. **第1周目 Yomi**：旁观宴会、狼方胜、被杀害→loop；建立规则认知（Key 04）。
3. **Infiltration（潜入）**：村内探查与被盘问，解锁人物 KEY。
4. **第2周目 Wit**：主动入场推理、人物秘密展开→仍无法破局（Key 16）。
5. **第3周目 Darkness**：人为操控痕迹（电子锁/迷香/恶狗/三车家）、狼爷爷真身、怪物登场→真相转向阴谋（Key 20）。
6. **第4周目 Myth**：集齐 KEY，与千枝实/绵羊/三车家对峙，天谜地解→真结局，loop 闭合（需 Key 01）。

## 3.7 真相揭示的"信息增量"递进表

| 阶段 | 新增关键信息 | 对"三车家阴谋 / 黄泉忌之宴本质"的认知变化 |
|------|--------------|--------------------------------------------|
| Yomi（第1周目） | 宴会规则、加护职能、死亡回溯机制 | 仅知"神罚式狼人杀"，视为不可违逆的村俗 |
| Wit（第2周目） | 各村民秘密 KEY、规则可被质疑（貉/第五职能） | 从"旁观"到"参与"，怀疑规则并非铁律 |

## 3.9 本章小结：周目即信息进度

《人狼村之谜》的主线并非按"第一章/第二章"线性铺开，而是借 **Yomi→Wit→Darkness→Myth 四个主线周目 + Dense Mist/Infiltration 等子阶段** 的轮回结构，把信息像拼图一样分轮次交付。主角每多死/多活一轮，就多掌握一块事实：从"规则认知"（Yomi），到"人物关系网"（Wit），再到"阴谋本质"（Darkness），最终在 Myth 收束为完整真相。KEY 系统则从机制上保证了"信息递进"与"玩家探索"的同构——这正是该剧本文体最被评测肯定的精巧之处 [机核 GCORES](https://www.gcores.com/talks/1005995)[VG 电玩帮 评测](https://www.vgover.com/news/39034)。下一章将聚焦上述"引爆点"是如何被逐层铺设并集中释放的。
