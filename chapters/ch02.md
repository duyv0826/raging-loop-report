# 第2章 主要人物及其身份、关系与立场

> 本章聚焦《人狼村之谜》（Rei-Jin-G-Lu-P / Raging Loop，KEMCO，编剧 amphibian）的主要登场人物。核心论点在于：本作的人物关系之所以错综复杂，关键在于**"人物即角色扮演"**——休水村在"黄泉忌之宴"中把狼人杀的阵营与职业，映射到每一位村民的"神明加护"身份之上。理解人物，必须先理解他们"表面村民身份""宴会角色（狼人杀职业）""真实立场"这三重错位。

---

## 2.1 概览：人物即"角色扮演"

《人狼村之谜》最根本的设计，是把桌游"狼人杀"的规则嵌入了一个封闭的、看似真实的山村社会。据萌娘百科的角色与设定条目，休水村在"血雾"笼罩后会举行"黄泉忌之宴"，村民被神明分配各自的角色，并通过讨论与投票"吊死"狼神（[萌娘百科·人狼村之谜](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C)）。

角色分配与通行的狼人杀规则略有差异，据网易一篇详细评测梳理，本作设定为：

- **蛇**：每晚可查验一人是否为狼，对应"预言家"；
- **蜘蛛**：每晚可保护一人（不能保护自己），对应"守卫"；
- **乌鸦**：可查验死者是否为人类，对应"灵媒/验尸"；
- **猿猴**：有两人，互相知晓对方身份，对应日本本子的"共有者"；
- **狼**：每晚可血祭一人；
- **村民**：无特殊能力；
- 另有一个"某神秘角色"（剧情关键，涉及核心剧透）（[网易·《人狼村之谜》评测](https://www.163.com/dy/article/FGRNNAQG05269PPR.html)；相关规则校正亦见 [NGA·朝花夕拾No.15](https://nga.178.com/read.php?tid=22433268)）。

**分析解读**：这套映射意味着，同一个角色（如房石阳明、卷岛春）在不同周目会被随机赋予不同身份——旁观者、神职、狼，乃至村民。NGA 帖子即指出，"身份的分配会获得变化"，"最为重要的是'身份'的分配会获得变化"，这既是破局的难点，也是让玩家从各视角领略狼人杀魅力的设计巧思（[NGA·朝花夕拾No.15](https://nga.178.com/read.php?tid=22433268)）。因此，"人物关系"不能只看血缘与亲缘，还必须叠加上"宴会阵营"这一维度。

## 2.3 主人公与"谜之少女"

### 房石 阳明（ふさいし はるあき / Fusaishi Haruaki）
24 岁，故事开篇自称是东京大学医学院的研究生、在机车旅行中因事故跌入"皿永"而被芹泽千枝实所救（[萌娘百科·人狼村之谜](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C)；[百度百科·人狼村之谜](https://baike.baidu.com/item/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C/18841704)）。但剧情揭示其**真实身份是推理小说家，本名不明**，"房石阳明"只是众多笔名中最常用的一个，甚至未向交往两年的前女友透露真名；他话术一流、习惯说谎，自称"性格很扭曲"，口癖为"诶多（ええと）"（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。

其核心能力是**死亡回溯**：每次在宴中死亡都会回到发生事故的那一夜，并保留每一轮轮回的记忆。这些记忆以游戏中的 **KEY 系统**承载——KEY 既是线索，也是男主独立存档之外的记忆（[百度百科](https://baike.baidu.com/item/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9C/18841704)）。

**立场分析**：房石阳明是整场阴谋的"局外人"与"破局者"。机核评测评价其"双商在线""无论在何种绝境都能理性思考"，是"值得被喜欢的人"（[机核·速通打卡](https://www.gcores.com/talks/1129770)）。但社区对其评价存在分歧：有人视其为"玩家的化身"，也有人（如 Stage1st 讨论）认为他更像"作者的化身"——一个"从头到尾没有一句实话"、在感情上"绝对是个王八蛋"的复杂角色（[Stage1st·人物印象](https://stage1st.com/2b/thread-2256040-1-1.html)）。一处**事实争议**需特别标注：番外篇"绵羊"曾推测男主拥有超能力，但官方（作者 QA）已澄清房石阳明并非超能力者，番外五仅是某角色的猜测，并非定论（[NGA·通关讨论](https://bbs.nga.cn/read.php?tid=39114781&page=2)）。

### 咩子（めえこ / Meiko）——本章所指"谜之少女"
任务中的"谜之少女"在本作中最合理的对应者是**咩子**。百度百科明确将其身份标注为"迷路的孩童 / 少女"，年龄约 4 岁（[百度百科](https://baike.baidu.com/item/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c/18841704)）。她于男主抵达休水前一天被千枝实从皿永捡回，因只会"咩~咩~"地哭而得名，本名、住址均不明，由回末李花子照顾（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。

剧情揭示其**本体是克苏鲁神话中的黑山羊幼崽**，暴露模式中写到她在最后一次轮回吞噬了李花子的"土蜘蛛"、阻止了悲剧；其真实身份是官方前传/外传《死亡竞赛恋爱喜剧》的女角之一"东护美弥"（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。

**立场分析**：咩子是整场轮回的"掌管者/入侵者"。她并非村民阵营，而是凌驾于宴会之上的超自然存在，是轮回得以持续与终结的关键变量。需注意：咩子实为幼童而非字面意义的"少女"，将"谜之少女"等同于她属于合理推断；若读者将"谜之少女"理解为女主角芹泽千枝实，则属另一解读（见 2.4）。

### 美佐峰 美辻（みさみね みしづ / Misamine Mishizu）
男主在旅途最初遇到的暴躁便利店店员，真实身份是男主交往两年的前女友，因闹别扭未相认；她也是神秘组织"绵羊/美羊羊"的成员，为调查轮回现象而来，**正是房石阳明能在轮回中保留记忆的原因**（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。她是连接"超自然轮回"与"现实观测"的枢纽人物。

## 2.4 三车家与阴谋线核心

本作"村庄阴谋"的主线，由藤良村（上藤良）的**长者四家**主导。一篇设定考据长文指出，约 380 年前江户幕府时代，伏良（后演变为藤良/休水文字游戏）由长者四家分管，其象征与职责为：**三车家以蛇为象征、掌管司祭与政治；日口家以猿猴为象征、掌管饮食与锻造；能里家以乌鸦为象征、掌管医药；回末家以蜘蛛为象征、经营私娼**（[街机站·设定考据](http://www.jiejizhan.com/xz/27876.html)）。这恰好与宴会的角色体系（蛇/猿猴/乌鸦/蜘蛛）一一对应——**家族图腾即宴会神职**，是"人物=角色扮演"的深层注脚。

### 三车家（みつむら / Mitsumura，英文作 Miguruma）
三车家是"黄泉忌之宴"这一杀人仪式的最初设计者，以蛇为象征、掌握司祭与政治权力（[街机站](http://www.jiejizhan.com/xz/27876.html)；[Pinocchiopedia·Raging Loop](http://pinocchiopedia.com/wiki/Raging_Loop) 称其为"Miguruma clan, a powerful family … devised the Feast"）。NGA 讨论进一步厘清：上藤良人大多不知休水真有超自然现象，但**三车家知晓内幕**；日口家"知道有阴谋但不过问，三车家有什么需要就协助"；黄泉忌之宴本质上是防止休水放逐地之人揭竿而起的压制机制（[NGA·一口气通了人狼村](https://ngabbs.com/read.php?tid=31223780)）。

> **名称说明**：日文汉字为「三車」（みつむら），中文繁体作"三車家"、简体常作"三车家"，英文转写"Miguruma/Mitsumura"。本章统一采用任务给定的「三車家」，并以"三车家"作为简体写法。

### 回末 李花子（うえまつ りかこ / Uematsu Rikako）
27 岁，回末家（蜘蛛/私娼）的现任长者，白发红瞳。剧情揭示其为**最终 BOSS**：土蜘蛛的末裔，拥有吸收污秽、控制梦境的超自然能力，背负强烈怨念，为实现家族夙愿而发动"回溯"，并知晓操纵黄泉忌之宴的黑幕（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。她是轮回中保留记忆者之一。

**立场分析**：李花子是"操控者"，但更准确地说，是被蒙蔽的复仇者——她想借三车家的人狼游戏达成全灭结局以"灭世"，却因自身"狼人杀太菜"必须依靠男主破局（[JJwxc 讨论](https://bbs.jjwxc.net/showmsg.php?board=3&boardpagemsg=37926&id=2536404)）。社区对她的塑造评价两极：奶牛关评测称赞其"从纯情逐渐变成傲娇"的潜力（[奶牛关·评价](https://webmaster@cowlevel.net/game/f724e450778327dc10647650167fdd1d/review/3994339)），而 Stage1st 多位用户批评四周目为机械降神而"把李花子人设给毁了"、强行黑化为反派（[Stage1st](https://stage1st.com/2b/thread-2256040-1-1.html)）。

### 能里 清之介（のさと きよのすけ / Nosato Kiyonosuke）
32 岁，能里家（乌鸦/医药）现任家主之弟，曾是医学博士，因出身"上藤良"而有些轻视休水人，却深爱同为上层来的李花子（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。童年经历霍乱、被年幼的李花子所救，立誓给她幸福。

**立场分析**：从"被蒙蔽的特权阶层"逐渐转变为男主的盟友。Stage1st 用户称其"成长曲线和（与玩家的）情感沟通塑造得教科书级别"，"初期多讨厌他，后期就成反比多钦佩他"，并影响了《古诺西亚》中"拉齐奥"这一角色的塑造（[Stage1st](https://stage1st.com/2b/thread-2256040-1-1.html)）。

### 织部 香织（おりべ かおり / Oribe Kaori）
37 岁，未亡人，休水公共食堂经营者，来自东北，丈夫属于长者四家中的**日口家**，丧夫后被送到休水（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。平日慈母，精神崩溃后则是"往饭里放乌头、撒毒全村"的鬼子母性扭曲形象。

**立场分析**：典型的"被蒙蔽者"，其悲剧源于对两个儿子的过度保护与信仰崩塌。社区常以"乌头拌饭"梗调侃（[Stage1st](https://stage1st.com/2b/thread-2256040-1-1.html)）。

## 2.5 村中关键村民与"高中生三人组"

### 高中生三人组（休水唯三的高中生）
- **卷岛 春（まきしま はる / Makishima Haru）**：15 岁，卷岛宽造之孙女，父母因事故去世。八年前闯入举办黄泉忌之宴的休水，目睹母亲死于宴会后意外复活了最早的"山神/貉神"，与之形成一体两面的关系（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。**立场**：反抗者、关键变量；社区称其"所有角色中最具未来发展潜力""大恶人"。
- **织部 泰长（おりべ やすなが / Oribe Yasunaga）**：16 岁，织部长子，冷静沉着、是年轻人中的领导者，对千枝实有过年上控的暗恋，在母爱面前自卑（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。**立场**：反抗者、分析者；微博 repo 称其"一直保有自己的思考，锲而不舍追求属于他的正确性"（[微博 repo](https://weibo.com/ttarticle/p/show?id=2309405006092945195121)）。
- **酿田 近望（かもしだ ちかもち / Kamoshida Chikamochi）**：16 岁，能里清之介之侄，曾是能里家嫡子因缺乏传统道德观被废嫡送至休水；电波男、喜欢女装、直觉可怕（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。**立场**：旁观者、洞察者。

### 村中长老与权威
- **卷岛 宽造（まきしま かんぞう / Makishima Kanzō）**：61 岁猎人，春的爷爷，固执可靠、曾参加黄泉忌之宴，是村中实质领袖（[百度百科](https://baike.baidu.com/item/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c/18841704)）。**立场**：被蒙蔽的权威。
- **山胁 多惠（やまわき たえ / Yamawaki Tae）**：73 岁老妇人，休水代表与精神领袖，信仰虔诚、排斥外乡人（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。**立场**：被蒙蔽的虔诚信徒。

### 狼爷爷 / 木田德治
表面是疯疯癫癫、终日喊"狼来了"的老头，实则**装疯卖傻**。真名木田德治，是 60 年前藤良村"20 户杀人案"的主犯，逃脱刑罚后意外发现黄泉忌之宴幕后黑手**三车家的秘密**，遂与三车达成交易，作为宴会的"秩序维持者"在休水卧底；他从未相信神明，被男主评价为"天生的大恶人"。在最后一次轮回中欲刺杀男主，被咩子的草结绊倒、刀捅入嘴而死，是**全作主要人物中唯一真正的死者**（[萌娘百科](https://zh.moegirl.org.cn/%E4%BA%BA%E7%8B%BC%E6%9D%91%E4%B9%8B%E8%B0%9c)）。

## 2.7 阵营映射小结：理解人物关系的钥匙

把上述人物放回"三重身份"框架，可以清晰看出本作人物关系的结构性张力：

1. **血缘/亲缘层**：织部香织—泰长—义次（母子、兄弟）；卷岛宽造—春（祖孙）；能里清之介—酿田近望（叔侄）；芹泽千枝实—三车家（被逐出的孙女）。这些是"日常休水"的人际关系。
2. **宴会阵营层**：每轮随机分配的蛇/蜘蛛/乌鸦/猿猴/狼/村民，决定谁在夜晚杀人、谁被保护、谁被查验。这是"死亡游戏"的人际关系。
3. **真实立场层**：操控者（三车家、被利用的李花子）、被蒙蔽者（多数村民、长老）、反抗者（房石阳明、高中生三人组、后期盟友）、旁观者（马宫、桥本、咩子/美佐峰）。

**核心结论**：《人狼村之谜》的人物魅力，正来自这三层的错位与撕扯——一个在宴会上冷酷"狼"可能是你朝夕相处的邻人，一个"被吊死"的村民可能正是操控全局的复仇者。正如机核评测所言，制作组以"扎实的剧本功力"让一同生活多年的乡邻在生死博弈中暴露出"同窗好友、母子这样关系非比寻常的存在"，从而把狼人杀从轻松桌游变成了真实的伦理困境（[机核·Steam评测](https://www.gcores.com/talks/1005995)）。而"人物即角色扮演"这一设定，正是解读全部人物关系网络的钥匙。
